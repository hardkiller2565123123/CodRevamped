# CodRevamped

**CodRevamped** is an open-source preservation project focused on restoring **offline and local functionality to newer Call of Duty games**.

Many modern Call of Duty titles depend heavily on online services for startup, menus, progression systems, and gameplay features. When those services change, disappear, or stop supporting older builds, parts of those games can become inaccessible.

CodRevamped works to restore as much of that functionality as possible through custom clients, compatibility patches, and local backend emulation.

> **CodRevamped does not include Call of Duty game files. You must legally own and provide your own supported game files.**

---

# Game Support

Support is handled per game and per build. A working client for one version of a game does not automatically mean other versions are compatible.
Some builds may only boot or reach menus while others may support actual offline gameplay.
